# خريطة التصميم والكود

## ملفات التنفيذ الأساسية

| الملف داخل `portable-react` | وظيفته |
|---|---|
| `app/page.tsx` | الشاشة كاملة، اختيار الفترة والدائرة والجلسة، التبويبات، خلايا الإدخال، النوافذ، حفظ واسترجاع المسودة. |
| `app/statistics.ts` | أنواع البيانات، بيانات التجربة، أنواع الأحكام والمؤجلات، الحسابات، فحص الاتزان والتوزيع، حركات التقصير. |
| `app/globals.css` | الهوية البصرية كاملة، متغيرات الألوان، الجداول، حقول الأرقام، النوافذ، شريط الأوامر، نقاط الاستجابة. |
| `components/ui/` | Tabs وSelect وTable وDialog وAlertDialog وButton المستخدمة فعليًا. |
| `lib/utils.ts` | دمج أسماء CSS classes باستخدام clsx وtailwind-merge. |
| `src/main.tsx` | تركيب الشاشة على عنصر root في نسخة React المستقلة. |
| `index.html` | اللغة العربية وRTL والعنوان ووصف الصفحة والأيقونة. |
| `vite.config.ts` | بناء مستقل وأصول بروابط نسبية وتعريف اختصار الاستيراد `@/`. |
| `postcss.config.mjs` | معالجة Tailwind CSS. |
| `vendor/` | CSS الإضافي الخاص بالمكونات وترخيصه الأصلي. |
| `public/favicon.svg` | أيقونة الموقع. |
| `scripts/serve-preview.mjs` | معاينة `dist` محليًا بمكتبات Node الأساسية. |

| النص الأساسي | `#172a43` |
| الشريط العلوي | `#152c49` |

| حدود العناصر | `#dce4ed` |

| اتجاه المستند | `lang="ar" dir="rtl"` |
| حجم النص الأساسي | 16px |
| حجم الرقم الإجمالي بالبطاقة | 31px |

الأولوية دائمًا للقيم الفعلية في CSS، فبعض العناصر لها حالات وأبعاد متخصصة. لا تستبدل الخط أو الألوان تلقائيًا، ولا تضف لونًا بنفسجيًا. حافظ على الأعمدة المحسوبة وخلايا الإدخال في شكلين واضحين، وثبات عمود سنة القيد أثناء التمرير الأفقي داخل الجدول.

## مسار الاستخدام

1. اختيار سنة وشهر الإحصائية ونوع مدني كلي.
2. فتح شاشة الإدخال ثم اختيار الدائرة ثم جلسة تابعة لها.
3. ظهور نوع القضية والاختصاص من الجلسة، مع أربع بطاقات للإجماليات والمراجعة.
4. استخدام تبويبات الإنتاج، أحكام القضاة، وتوزيع المؤجلات.
5. حفظ المسودة أو فحص الإحصائية والانتقال من الملاحظة إلى موضعها.

## ربط البيانات

| المعرف البرمجي | المعنى |
|---|---|
| `ANNUAL` | العام القضائي التجريبي وحدوده. |
| `CIRCUITS` و`SESSIONS` | دوائر العام وجلساتها والاختصاص ونوع القضية. |
| `CIRCUIT_JUDGES` | قضاة الدوائر الافتراضيون وصفاتهم. |
| `YEARS` | شرائح سنوات القيد المعروضة. |
| `JUDGMENTS` و`GROUPS` | الأحكام المدنية وشجرتها وتصنيفها. |
| `REASONS` | ستة أسباب / مسارات لتوزيع المؤجلات. |
| `Row` | بيانات صف سنة قيد، بما فيها أحكام القضاة والتوزيعات. |
| `Sheet` | مجموعة صفوف سنة القيد لإحصائية. |
| `Data.records` | مسودات بمفتاح مركب من الشهر ورقم الجلسة. |
| `Data.transfers` | حركات التقصير التجريبية ومصادر رصيدها. |
| `getStats` | حساب المجاميع وملاحظات الاتزان واكتمال التوزيع. |
| `previousFor` | السابق الصافي بعد خصومات التقصير. |
| `availableToShorten` و`addTransfer` | التحقق من الرصيد وإضافة التقصير في النموذج. |
| `normalize` و`validNumber` | تحويل الأرقام العربية والتحقق من عدد صحيح غير سالب. |
| `makeDemo` و`makeBlank` | إنشاء بيانات تجربة أو نموذج فارغ. |
| `isData` و`migrateV2` | فحص بيانات التخزين المحلي والتوافق مع المسودة السابقة. |

في المنتج النهائي تُستبدل الثوابت بمصادر بيانات معتمدة، وتُعاد قواعد التحقق على الخادم. لا تحول فهارس المصفوفات مثل رقم القاضي أو سنة الصف إلى معرفات قاعدة بيانات دائمة.

## الحسابات الموجودة في النموذج

- المقدم = السابق الصافي + الجديد + المعجل والمجدد + التقصير الوارد.
- الخارج = جميع الأحكام + الشطب + المؤجل دون أحكام.
- المطلوب توزيعه = المؤجل دون أحكام + الأحكام الفرعية والإثبات.
- مد الأجل والإعادة للمرافعة من بيان القضاة المستقل، ويدخلان المؤجل، ولا يُضافان إلى مجموع الأحكام.
- الفرعي والإثبات يدخلان مجموع الأحكام مرة واحدة، ويحتاجان توزيعًا على الشهور لأن الدعوى لم تنتهِ.
- التوزيع يدوي؛ لا يكمل النظام الشهر الأخير بالمتبقي.

هذه المعادلات تصف النموذج المدني الحالي. لا تعممها تلقائيًا على مسار الجنح أو على جميع الأنواع دون الرجوع إلى متطلبات النظام.

## تنبيهات للإيجنت قبل تحويله إلى نظام فعلي

- النموذج يدمج المعجل والمجدد في حقل واحد؛ هذا ليس دليلًا على وجوب دمجهما بكل أنواع الإحصائية.
- `IMPORTED` أرصدة افتراضية داخل `statistics.ts` وليست شاشة للأرصدة الافتتاحية.
- لا يوجد توزيع جنائي آلي أو قرارات ندب وإجازة حقيقية أو دعم ديناميكي للقضاة الستة.
- لا يوجد قفل رسمي بعد الاعتماد؛ زر الفحص يتحقق من النموذج فقط.
- فحص التقصير داخل المتصفح لا يوفر حماية من مستخدمين متزامنين؛ هذا يحتاج خدمة ومعاملة على الخادم.
- النصوص المتعلقة بربط العام التالي أقدم من قرار فصل الأرصدة السنوية؛ احتفظ بالأصل للمرجع وطبق القرار الأحدث عند تنفيذ مجال العمل.
- استدعاء `document.modelContext` في الواجهة اختياري ومحاط بفحص وجوده؛ لا يحتاجه الموقع المستقل ولا يعتمد عليه حفظ البيانات.
