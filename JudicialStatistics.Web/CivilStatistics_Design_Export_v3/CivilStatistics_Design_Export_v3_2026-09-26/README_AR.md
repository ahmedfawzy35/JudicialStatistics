أعطه هذه الحزمة كاملة، واطلب منه قراءة `AGENT_PROMPT_AR.md` ثم `DESIGN_AND_CODE_MAP_AR.md`. المجلد المناسب للتنفيذ في مكان آخر هو `portable-react`.

## أسرع تشغيل للمعاينة

ثبّت Node.js بإصدار يحقق شرط `package.json`، ثم افتح Terminal داخل `portable-react`:

```powershell
node scripts/serve-preview.mjs
```

افتح `http://127.0.0.1:4173`. هذا الأمر يعرض النسخة المبنية الموجودة بالحزمة، ولا يحتاج تثبيت مكتبات npm. لإيقافه اضغط `Ctrl+C`.

لا تفتح `dist/index.html` بالنقر المزدوج؛ شغّل الخادم المحلي أعلاه حتى تُحمّل ملفات JavaScript كوحدات بصورة صحيحة.

## تشغيل المصدر وتعديله

المتطلب المعلن: Node.js `>=22.13.0`. الإصدارات المثبتة أثناء تصدير هذه الحزمة موضحة في `export-manifest.json`.

من مجلد `portable-react`، إن كان pnpm متاحًا:

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

يوجد أيضًا مسار npm:

```powershell
npm install
npm run dev
```

افتح `http://127.0.0.1:5173`. استخدام pnpm يستفيد من القفل المرفق. استخدام npm يُنشئ قفلًا خاصًا به؛ لم يُرفق `package-lock.json` ولم تُختبر تثبيته من الإنترنت في هذه الجولة.

لبناء نسخة جديدة بعد التعديل:

```powershell
npm run build
npm run preview
```

البناء يتحقق من TypeScript ثم يولد `dist`. إعداد `base: "./"` يجعل روابط الأصول نسبية حتى يمكن استضافة الناتج داخل مجلد فرعي. لا يحتاج المشروع المستقل مفاتيح API أو ملف بيئة أو حساب ChatGPT.

## داخل مشروع ASP.NET Core / Visual Studio

إذا كان مقصدك `JudicialStatistics.Web`، فاختر مع الإيجنت المسار الذي يناسب بنية المشروع الموجودة:

1. الاحتفاظ بالواجهة React: تُبنى الواجهة ثم تُستضاف ملفات `dist` في مسار مخصص من `wwwroot` وتُربط بخدمات ASP.NET Core عند تنفيذ الربط.
2. استخدام Razor أو Blazor: ينقل الإيجنت هيكل الشاشة والتنسيقات والسلوك إلى مكونات التقنية القائمة، مع مقارنة النتيجة بالأصل. ملفات TSX ليست Razor، وتغيير امتدادها لا يحولها إلى C#.

لا يلزم إعادة إنشاء المشروع كله للحصول على الشكل نفسه. لا تستخدم إعدادات نشر `original-source` لنشر المشروع الجديد؛ هي مرجع للبيئة الأصلية فقط.

## ما الذي يعمل بالفعل؟

- شاشة اختيار السنة والشهر، ثم اختيار الدائرة والجلسة التابعة لها.
- كشف الإنتاج حسب سنة القيد، وأحكام القضاة، وتوزيع المؤجلات يدويًا.
- عرض المجاميع وملاحظات عدم الاتزان والخانات الناقصة.
- بيان مد الأجل والإعادة للمرافعة لكل قاضٍ خارج مجموع الأحكام.
- تقصير تجريبي بين الشهور مع فحص الرصيد وحساب الخصم والإضافة.
- حفظ المسودة في `localStorage` واستعادتها في المتصفح نفسه.
- التنقل باللوحة ومكونات RTL والنوافذ والقوائم والتصميم المتجاوب.

## حدود الكود الحالي

هذه **واجهة تجريبية كاملة للمدني الكلي**، وليست تنفيذًا كاملًا لنظام الإحصاء المتفق عليه. لا توجد قاعدة بيانات تشغيلية أو API مستخدمة بالشاشة، أو دخول وصلاحيات، أو اعتماد رسمي وقفل على الخادم، أو تقارير Excel. وجود ملفات `db` وأمثلة D1 في المصدر الأصلي جزء من القالب ولا يعني اكتمال الربط.

العام 2025/2026، الدوائر والجلسات والقضاة وسنوات القيد وأرصدة التجربة معرفة في الكود. عدد القضاة في منطق النموذج ثلاثة، والتوزيع مهيأ حتى 12 شهرًا. بقية أنواع الإحصائية، ومنها مسار الجنح بصف واحد، ليست منفذة في هذه الواجهة.

بيانات المسودة على الموقع القديم لا تنتقل تلقائيًا إلى النطاق الجديد لأن التخزين مرتبط بأصل الموقع والمتصفح. الحزمة لا تحتوي بيانات المستخدم المحفوظة في متصفحه.

هناك نصوص قديمة بالنموذج تتحدث عن «ربط العام الجديد». هذه النصوص جزء من النسخة المنشورة؛ عند تنفيذ النظام الفعلي يطبق قرارك الأحدث: أرصدة افتتاحية مستقلة لكل عام تُدخل يدويًا، دون ترحيل آلي مرتبط بالعام السابق.

## المصدر والتراخيص

المصدر المباشر هو مشروع المستخدم والإصدار المنشور 3، وليس إعادة رسم من صورة. كود `app/page.tsx` و`app/statistics.ts` و`app/globals.css` والمكونات المستخدمة منقول دون تغيير في النسخة المستقلة. المضاف هو نقطة تشغيل React وإعداد Vite وملفات التشغيل والتوثيق. الخط الأصلي هو `Tahoma, Arial, sans-serif`؛ قد يختلف عرضه على جهاز لا يحتوي Tahoma. تراخيص الأصول المرفقة محفوظة في `vendor`، وتظل تراخيص المكتبات الخارجية سارية.
